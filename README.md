🚕 OLA Ride Booking Analytics Dashboard

📌 Project Overview

This project focuses on analyzing OLA ride-booking data through an interactive dashboard. The dashboard provides valuable insights into booking performance, revenue generation, vehicle-type performance, ride cancellations, and customer satisfaction.

The objective is to transform raw booking data into meaningful business insights that can help understand operational performance and support data-driven decision-making.

🎯 Project Objectives

- Analyze overall ride-booking performance.
- Track total bookings and successful bookings.
- Evaluate booking value and revenue trends.
- Compare performance across different vehicle categories.
- Identify major reasons for ride cancellations.
- Analyze customer and driver ratings.
- Understand customer payment preferences.
- Monitor daily ride-booking trends.

📊 Dashboard Modules

1. Overall Analysis

- Total Bookings
- Total Booking Value
- Booking Status Breakdown
- Ride Volume Over Time
- Overall business performance analysis

2. Vehicle Type Analysis

- Prime Sedan
- Prime SUV
- Prime Plus
- Auto
- Mini
- Bike
- E-Bike

Analyzes booking value, successful booking value, average distance travelled, and total distance travelled for each vehicle category.

3. Revenue Analysis

- Revenue by Payment Method
- Daily Revenue Trends
- Top 5 Customers by Booking Value
- Cash, UPI, Credit Card, and Debit Card analysis

4. Cancellation Analysis

- Ride cancellations by drivers
- Ride cancellations by customers
- Cancellation reasons
- Booking cancellation patterns

5. Rating Analysis

- Average vehicle ratings
- Customer ratings
- Comparison of customer satisfaction across vehicle categories

🔍 Key Insights

- Total bookings reached approximately 103.02K.
- Total booking value was approximately 57M.
- Successful bookings accounted for approximately 63.97K rides.
- Average vehicle ratings were around 4.0.
- Cash and UPI were the leading payment methods in the displayed revenue analysis.
- The dashboard highlights different cancellation reasons for both drivers and customers.
- Vehicle categories show differences in booking value and distance travelled.

Note: These figures represent the dashboard values for the displayed reporting period and may change with filters.
